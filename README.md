# Nova3d_project_page

Static project page for `Nova3D: Code-Native Generation of Programmable 3D Assets`.

**Live project page:** https://raresense.github.io/Nova3d_project_page/

## Run

From this folder:

```powershell
python -m http.server 4173
```

Then open:

```text
http://127.0.0.1:4173/
```

Comparison and feature media are in `assets/figures/`.

## Add Showcase Assets

Current gallery turntables are in `assets/showcase/`. The textured G-Wagon PBR clip is used in the PBR section from `assets/figures/`.
Use the same filenames to replace clips, or update `src/app.js` to add more gallery entries.
